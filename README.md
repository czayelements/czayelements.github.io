# czayelements.github.io

The landing page for [elements.czaylabs.com](https://elements.czaylabs.com). It lists the projects of the `czayelements` organisation. Each project's documentation is served from its own repository's GitHub Pages under the same domain:

- `elements.czaylabs.com/zay-ui/` → [czayelements/zay-ui](https://github.com/czayelements/zay-ui)

A project site only needs its own Pages workflow with `basePath` set to `/<repository-name>`; the organisation domain is inherited.
